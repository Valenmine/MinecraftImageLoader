#  Minecraft Image Loader

A custom Minecraft plugin to easily render and integrate images directly into the game!

---

##  About

This plugin allows players and administrators to load custom images and display them inside Minecraft. It is perfect for decorating spawn areas, creating custom signs, or adding artwork to your server!

---

## Features

- Load custom images into the game easily.
-  Compatible with modern Spigot / Paper server environments.
-  Smooth rendering using maps and item frames.

---

##  Installation

1. Download the `.jar` file from the repository or releases.
2. Place the `.jar` file into your server's `plugins/` directory.
3. Restart or reload your server.
